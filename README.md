# ✈️ FLIGHT-PRICE-PREDICTION-Using-Machine-Learning

## 📊 Project Overview
This repository presents a **Machine Learning–based Flight Price Prediction system** that analyzes historical flight data to estimate ticket prices. The model helps users understand how different factors such as airline, source, destination, duration, and travel date influence flight fares.

## 🎯 Objective
The main objective of this project is to:
- Predict flight ticket prices accurately using historical data.
- Analyze the impact of different features on flight pricing.
- Provide a simple and user-friendly interface for price prediction.
- Help travelers make informed booking decisions.

## 🧩 Features
- **Data Preprocessing**: Handling missing values, feature encoding, and scaling.
- **Exploratory Data Analysis (EDA)**: Visualization of price trends and patterns.
- **Machine Learning Model**: Trained using regression algorithms for price prediction.
- **User Input Prediction**: Predicts ticket price based on user-provided flight details.
- **Model Evaluation**: Performance analysis using metrics like RMSE and R² score.

## 📁 Repository Contents
- `app.py` → Flask application for flight price prediction.
- `model.pkl` → Trained machine learning model.
- `flight_price_prediction.ipynb` → Jupyter Notebook for data analysis and model training.
- `templates/` → HTML files for the web interface.
- `static/` → CSS and assets for UI styling.
- `requirements.txt` → Required Python libraries.
- `README.md` → Project documentation.
